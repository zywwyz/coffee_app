# 个人豆管理改进实施计划

**Goal:** 落地用户确认的个人豆表单、养豆状态与已喝完评分排序。历史图片同步仅解释，本轮不改。

**Architecture:** 保留目录和饮用记录的独立快照；新增 RESTING，个人豆状态为 ACTIVE/DISCONTINUED/RESTING。Room v5 仅迁移个人豆 ARCHIVED→DISCONTINUED，保持所有其他数据。备份接受旧 v1–v4 并在恢复时相同转换，新增 v5 域校验。评分按 sourceItemId 和 PERSONAL_BEAN 聚合，排除 null；无评分置底、同分以名称/id 稳定排序。日期按日历日差计算，兼容 API 23。

**Tech Stack:** Kotlin / Compose / Room / Robolectric / Android DatePickerDialog。

- [x] 补定向测试并观察旧实现失败：下拉选择/自定义处理法、去默认冲煮、日历选择、状态与跨月年/DST天数、评分动态排序、旧数据与备份。
- [x] 个人豆处理法建议：水洗、日晒、蜜处理、湿刨、厌氧发酵、二氧化碳浸渍；允许任意自定义非空文本。烘焙度建议：极浅烘焙、浅烘焙、中浅烘焙、中度烘焙、中深烘焙、深烘焙、极深烘焙；旧自定义值可显示。字段仍可选。
- [x] 购买/烘焙日期使用系统日历，显示 YYYY-MM-DD，支持清除；养豆中必须有有效且不晚于今日的烘焙日期。当天 0天。旧异常日期显示待补充而不伪造天数。
- [x] 移除个人豆默认冲煮方式输入，不清除旧字段/历史记录；新饮用个人豆记录不再套用目录默认冲煮方式。
- [x] 个人豆筛选和编辑仅出现正在喝/已喝完/养豆中；养豆行显示 x天，支持开始喝/喝完并在编辑器任意切换；已喝完按全部有效评分平均值降序、无评分最后。
- [x] Room v5与旧备份恢复中只转换个人豆归档状态，保留连锁旧状态和图片引用；不做删除或破坏性迁移；版本低于5不接受RESTING。
