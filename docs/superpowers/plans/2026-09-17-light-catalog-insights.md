# 轻量豆库与总结实现计划

**Goal:** 落地用户已确认的轻量画布，保持人工上传图片和离线工作。

**Architecture:** Kotlin Compose 展示层改版；豆库使用本地目录 Flow 汇总用于跨品牌搜索；保留现有编辑/图片租约/备份与数据库 schema。总结使用原计算结果绘制横条，无统计口径变更。日历和全局主题不改。

**Tech Stack:** Kotlin / Compose / Room v4 / Robolectric。

## 实施

- [x] CatalogRepository/CatalogViewModel/CatalogScreen：观察当前类型全部产品，跨品牌搜索（产品名和品牌名），品牌chips筛选；状态切换互相隔离、列表实时刷新。
- [x] 豆库根页：紧凑标题、新增菜单、两种目录tab、搜索、横滑品牌chips、48dp完整图产品行；保留新增品牌/产品和品牌管理入口；个人豆状态和编辑/归档保留。
- [x] 品牌产品页：改48dp缩略图列表，保留筛选、返回、编辑/删除及确认。
- [x] InsightsScreen：去纸点/胶带/大白卡；四指标可响应式换行、习惯摘要、类型与品牌横条、Top3、40dp图片回顾；所有真实指标和动作保留。
- [x] 定向测试：跨品牌搜索/组合筛选/目录切换、空状态、编辑和人工图片流程；总结横条真实数值、未知金额、月年导航、长名和320dp放大字。
- [x] 原生预览：豆库混合实拍/Logo/占位、搜索、个人豆与总结；目视检查，不修改日历。
- [x] reviewer审查有意义逻辑，处理findings；模块验证、lint、Debug APK、项目状态和README真实图更新。

## 边界

人工上传产品照片逻辑保持。无官方图片自动获取、网络、外部API、DB迁移或导入同步。轻量画布示意不意味着删除原有品牌占比、Top3产品或评分回顾等功能。未要求自动提交或推送。
