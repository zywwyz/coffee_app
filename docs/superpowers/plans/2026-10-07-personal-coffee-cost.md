# 个人咖啡规格与计价、历史照片详情 Implementation Plan

**Goal:** 突出历史实拍图，支持咖啡豆/挂耳采购规格及按用量计价，并允许手动覆盖。
**Architecture:** 延续Compose/Room。目录存采购基数，草稿与记录保存当次类型、规格基数、用量、价格模式及金额快照；采用整数分与精确十进制运算。Room v6兼容迁移与旧ZIP恢复。历史图片关联的revision/恢复世代保护保持。
**Tech Stack:** Kotlin / Jetpack Compose / Room / JUnit / Robolectric。

## 已决定的产品行为
- 日历当天详情：奶油纸底，卡片上方完整大图(Fit，约180–220dp)，品牌轻标题/产品主标题；评分和金额明确并列。备注、用量、冲煮方式次级信息；换图/编辑/删除仍可达。多杯纵向滚动，短屏大字体不裁切。
- 个人产品类型咖啡豆/挂耳咖啡。旧个人产品默认咖啡豆。采购总价可空或0元；咖啡豆总克重和挂耳总包数可选但填写必须正数，包数为整数。更换类型清除不适用规格。
- 咖啡豆饮用方式手冲/意式，用豆克数可选；挂耳默认1包，可改正整数包数。未填采购价、有效规格或用豆量时不伪造自动价，允许手动填写或价格留空。
- 金额计算只在最后一步四舍五入到分，避免先舍入单位价；豆:总价×本次克数÷总克重；挂耳:总价×本次包数÷总包数。禁止负数、无穷/溢出/零分母，精确整数/BigDecimal运算。
- 用户已明确允许手动改价，手动后用量变化不覆盖金额；恢复自动计算用当前记录保存的计价基数重算。新建读取当前目录，编辑已有记录保留当时基数（目录后来改价不追溯）。无采购基数的旧记录保持手动原价，不自动补算。
- 旧历史图片、评分、价格、日期、状态及新增/编辑退出修复保持。仅更换产品时获取新计价基数并重置不适用用量。草稿能跨重启保持类型/方式/用量/手动价模式。
- 统计新记录按手冲/意式/挂耳分类，旧个人记录维持原HAND_BREW快照，避免把意式统计为手冲。
- 本轮交付1.2/versionCode4，原包名原签名；不自动推送。
