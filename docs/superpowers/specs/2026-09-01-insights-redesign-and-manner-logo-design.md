# 总结页重设计与 MANNER Logo 更新规格

日期：2026-09-01
状态：待用户最终审阅
范围：Android App 的“总结”根页面与随包 MANNER 品牌 Logo

## 1. 背景与目标

当前总结页的信息密度和视觉层级不清晰，趋势图、品牌占比图和偏好排行不适合手机快速阅读；最好／最差记录缺少产品图片。当前 MANNER 随包 Logo 虽然在代码中等比显示，但其派生图形本身偏横，产生了纵向压缩的视觉感受。

本次目标：

1. 让总结页首先回答“这个月／今年喝咖啡的习惯如何”。
2. 以更年轻、轻量的卡片和图表展示饮用趋势、类型占比、品牌占比与偏好。
3. 精简排行，只保留有决策价值的 Top 3。
4. 最好／最差记录展示其历史产品图，并保持历史快照语义。
5. 使用用户提供的 MANNER Logo 图片，保持原始比例、完整图形和安全留白。

非目标：

- 不增加云端、网络或第三方图表依赖。
- 不修改 Room schema，不迁移历史记录。
- 不重新设计咖啡日历、豆库或底部导航。
- 不增加完整排行页面或“查看全部排行”功能。

## 2. 已选设计方向

采用“习惯故事线”布局：从本期总体习惯开始，依次展示饮用节奏、类型／品牌构成、Top 3 偏好和本期高光。未采用以最好产品大图为首屏的杂志布局，也未采用高密度数据仪表盘。

所有视觉 token 复用咖啡日历页：

- 奶油白页面背景；
- 深森林绿主色；
- 暖桃色强调；
- 白色圆角卡片；
- 浅暖灰描边；
- 现有圆角、间距和底部导航样式。

## 3. 页面结构

从上到下固定为：

1. “总结”页面标题。
2. 月度／年度双选切换。
3. 上一周期、当前周期、下一周期导航。
4. 习惯主卡。
5. 饮用趋势卡。
6. 咖啡类型与常喝品牌两个并列环形图卡。
7. Top 3 品牌与 Top 3 产品双栏卡。
8. 最好与最差产品双卡。
9. 现有底部根导航。

在窄屏上，卡片内容不得横向溢出；产品名称使用单行省略，完整名称通过记录详情查看。

## 4. 习惯主卡

主数字为本期总杯数。附属指标为：

- 饮用天数：同一自然日喝多杯只计一天；
- 最长连续饮用天数：按本地自然日计算；
- 平均评分：只包含填写过评分的记录；
- 与上期对比：显示杯数差值和方向。

总消费与杯均价格保留，但降为次要的两个小指标：

- 总消费只累加填写过价格的记录；
- 杯均价格的分母只包含填写过价格的记录；
- 本期没有任何价格时，两项均显示 `—`。

## 5. 饮用趋势

### 5.1 月度

趋势图使用累计杯数，避免按周统计只有 4–5 个离散点：

- 横轴为当月 1 日至最后一日；
- 深森林绿实线为所选月份累计杯数；
- 浅暖灰虚线为前一月份同期累计杯数；
- 当天没有新增记录时，累计线保持水平；
- 当前月只绘制到今天；前一月对照也只绘制到相同日序；
- 历史月份绘制完整月份，并与前一个完整月份比较；
- 月份天数不同，对照线只绘制双方共同存在的日序；当前月多出的日期只保留本月线。

### 5.2 年度

- 横轴为 1–12 月；
- 深森林绿实线为每月杯数，不采用累计值；
- 浅暖灰虚线为上一年度同期每月杯数；
- 当前年份只绘制到当前月；历史年份绘制完整 12 个月。

趋势图不再同时展示消费金额或评分，避免双轴和过多视觉编码。

## 6. 占比图

使用两个并列环形图。

### 6.1 咖啡类型

按记录杯数统计四类：

- 黑咖；
- 果咖；
- 奶咖；
- 手冲。

所有个人豆记录统一归入“手冲”。连锁产品使用其历史快照中的黑咖／果咖／奶咖分类。环形图中心显示本期总杯数，图例同时显示类别名称、杯数和百分比。

### 6.2 常喝品牌

按记录杯数统计品牌。环形图最多使用五个切片：

- 杯数最高的四个品牌；
- 其余品牌合并为“其他”。

少于或等于四个品牌时不显示“其他”。排序按杯数降序；杯数相同时优先显示最近喝过的品牌。

## 7. 偏好 Top 3

只展示：

- Top 3 品牌；
- Top 3 产品。

排名依据为本期饮用杯数。杯数相同时，以最近一次饮用时间较新的项目优先；仍相同时使用稳定名称／ID 顺序，保证界面不会在相同数据上随机变化。

产品聚合优先使用历史 `sourceItemId`；没有稳定来源 ID 时使用历史快照名称与品牌组成的稳定键。豆库删除或改名不改变既有记录的归组结果。

每项只显示名次、名称和杯数，不罗列完整产品集合，不新增“查看全部”。产品名称过长时单行省略。

## 8. 最好与最差

- 只使用填写过评分的记录；
- 最好为最高评分，最差为最低评分；
- 多条记录并列时，卡片展示最近喝过的一条；
- 并列数按不同产品计算，重复饮用同一产品不重复计数；
- 卡片标注“另有 N 款并列”；没有其他并列产品时不显示该文案；
- 只有一个已评分产品或所有已评分产品分数相同时，只显示“最好的一杯”，另一位置显示“本期评分一致”，避免同一产品同时作为最好和最差；
- 两张卡片均显示历史产品名称、品牌、评分和图片；
- 点击卡片打开对应历史记录详情。

图片严格使用保存记录时的快照，回退顺序为：

1. 历史产品实拍图；
2. 历史品牌 Logo；
3. 通用占位图。

豆库后来改名、换图或删除产品，不得改变旧总结中的历史展示。

## 9. 空状态与失败处理

- 无记录：主卡显示 0 杯、0 天；趋势、占比和排行显示简洁空状态，不绘制伪数据。
- 无评分：隐藏最好／最差双卡，显示“记录评分后可查看本期高光”。
- 无价格：总消费和杯均价格显示 `—`。
- 仅一个品牌／类型：环形图显示单色完整圆环，图例仍显示真实杯数和 100%。
- 图片不存在、损坏或无法解码：按产品图、品牌 Logo、占位图顺序回退；页面继续可用。
- 年月边界沿用现有 1..9999 保护，不能导航至非法周期。

## 10. 数据与组件边界

不修改数据库结构。`InsightsCalculator` 从现有 `DrinkRecord` 历史快照计算纯统计结果；展示模型补充：

- 月度累计点与对照点；
- 年度月杯数点与对照点；
- 类型占比条目；
- 品牌占比条目；
- Top 3 品牌／产品；
- 最好／最差记录的历史产品图与品牌 Logo 引用；
- 饮用天数、连续天数及消费辅助指标。

UI 拆分为可独立测试的卡片：习惯主卡、趋势卡、环形占比卡、Top 3 卡和评分高光卡。月度与年度共用相同卡片语言，只替换统计粒度和文案。

## 11. MANNER Logo

审计输入为用户提供的：

仓库必须保存该输入或其可审计副本，不能依赖开发机器绝对路径。生成过程：

1. 仅移除与图片边缘连通的纯白／近白背景；
2. 保留完整黑色三角、字框和字形；
3. 不重绘、不变形、不改变纵横比；
4. 等比缩放后居中到透明 512×512 画布；
5. 四周保留与其他日历 Logo 一致的安全留白；
6. 更新来源台账、文件 SHA 和 Android 解码像素指纹。

日历、豆库和产品图片回退使用同一随包 MANNER 资源。

## 12. 可访问性与交互

- 图表不能只依赖颜色表达信息；图例必须有文字、杯数和百分比。
- 深森林绿、暖桃、柔和薄荷与浅暖灰应保持可区分度。
- 可点击的最好／最差卡片具备明确语义描述和足够点击区域。
- 月度／年度切换、周期导航沿用现有语义标签与可用性边界。
- 动画仅用于轻微数值／图线过渡，不影响 Robolectric 截图稳定性；测试环境可禁用动画。

## 13. 测试与验收

### 13.1 计算测试

- 当前月累计线与上月同期；
- 不同月份天数的共同日序处理；
- 历史完整月份；
- 年度 12 月杯数与去年同期；
- 饮用天数与最长连续天数；
- 黑咖／果咖／奶咖／手冲分类；
- 品牌 Top 4 + 其他；
- Top 3 排序与并列稳定规则；
- 最好／最差最近并列代表；
- 价格缺失与杯均价格分母。

### 13.2 UI 测试

- 月度／年度切换及周期导航；
- 主卡、累计趋势、双环图、Top 3、最好／最差完整布局；
- 产品图 → 品牌 Logo → 占位图回退；
- 无记录、无评分、无价格；
- 长产品名称不破坏布局；
- 最好／最差点击打开正确记录详情。

### 13.3 Logo 与预览

- MANNER 输出为 512×512、比例不变、无非透明像素贴边；
- 背景透明且完整黑色图形未被裁切；
- 更新像素指纹；
- 生成包含真实产品图与新 MANNER Logo 的真实 Compose 总结页预览；
- 在手机宽度视口检查首屏、滚动、图例和底部导航。

## 14. 验收标准

1. 总结页与咖啡日历页视觉语言一致。
2. 月度趋势具有连续 1–31 日累计线和上月同期对照，不再只有 4–5 个周节点。
3. 同时展示四类咖啡占比和品牌占比双环图。
4. 品牌、产品排行各不超过三项。
5. 最好／最差显示历史图片并正确回退。
6. MANNER Logo 使用用户提供的完整三角版本，真机显示无压缩、拉伸或裁切。
7. 现有数据库、备份兼容、离线边界和其他根页面行为不回归。
