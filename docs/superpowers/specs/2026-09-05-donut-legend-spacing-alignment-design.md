# 总结页环图图例间距与数值对齐设计

日期：2026-09-05

## 背景

总结页将占比卡片改为整行宽布局后，环图容器与右侧图例直接相邻。图例色点从环图边缘开始，实际手机上产生贴边和视觉重叠。

图例目前还把杯数、分隔点和百分比拼成一个字符串。不同百分比宽度会推动整段统计值的起点，使 `4杯` 与 `0杯` 看起来不在同一列。

## 目标

- 环图与图例色点之间始终保留至少 16dp 的水平安全间距。
- 同一占比卡片中所有杯数垂直对齐。
- 同一占比卡片中所有百分比垂直对齐。
- 长品牌名继续完整换行显示。
- 320dp 窄屏和放大字体下不发生重叠或越界。

## 非目标

- 不改变环图尺寸、颜色、扇区计算或总杯数。
- 不改变品牌和咖啡类型的统计数据与排序。
- 不修改排行卡片、趋势图、数据库或 ViewModel。

## 布局设计

`DonutCard` 保持环图在左、图例在右：

- 环图继续使用 96dp 容器和 90dp Canvas。
- 环图容器与图例列之间使用固定 16dp 水平间距。
- 图例每行由色点、可换行名称、杯数、分隔点和百分比组成。
- 名称使用剩余宽度，不设置最大行数或省略号。
- 杯数放入固定宽度列并右对齐。
- 分隔点放入独立固定宽度列并居中。
- 百分比放入固定宽度列并右对齐。
- 杯数、分隔点和百分比保持单行。

固定列宽只负责对齐短统计值，不改变完整的无障碍描述。屏幕空间不足时，名称纵向换行，统计列不覆盖环图或名称。

## 测试与验收

先增加会在当前实现上失败的 Compose 回归测试，再修改生产布局。

验收覆盖：

1. 320dp 宽度下，环图右边界与第一枚图例色点左边界至少间隔 16dp。
2. 放大字体环境下仍满足相同间距，且图例内容位于卡片边界内。
3. `4杯` 与多个 `0杯` 的杯数文本拥有一致的水平列位置。
4. `100%` 与多个 `0%` 的百分比文本拥有一致的右边界。
5. 长品牌名继续多行展示并位于卡片内。
6. 现有 Insights Compose 与计算测试保持通过。

## 错误与空状态

空占比列表继续显示只有总杯数的环图，不渲染图例行。零杯图例仍显示为 `0杯 · 0%`，但视觉上由三个对齐列组成。
