# 总结页长名称完整展示设计

日期：2026-09-04

## 背景

总结页目前把“咖啡类型 / 常喝品牌”和“Top3 品牌 / Top3 产品”分别放在两组半屏双列卡片中。品牌图例和排行名称又被限制为单行省略，因此较长的品牌名以及“品牌 · 产品名”无法完整显示。

## 目标

- 品牌饼图图例完整显示品牌名称。
- Top3 品牌和 Top3 产品完整显示名称与数量。
- 在 320dp 窄屏上仍保持内容位于卡片边界内。
- 延续总结页现有奶油白、森林绿、暖色描边风格。
- 月度与年度总结保持一致的布局与行为。

## 非目标

- 不修改统计口径、排序规则或 Top3 截断规则。
- 不修改 Room、备份格式、ViewModel 数据结构或图片逻辑。
- 不重新设计饮用趋势、最好/最差卡片及底部导航。

## 布局设计

### 本期构成

“咖啡类型”和“常喝品牌”不再并排，各自占据一整行宽度。

每张占比卡片内部：

- 左侧显示现有环形图和总杯数。
- 右侧显示图例列表。
- 图例每行由色点、名称、杯数与百分比组成。
- 名称区域使用剩余宽度并允许自然换行，不设置单行省略。
- 杯数与百分比保持单行、右对齐，不覆盖名称。

### 常喝排行

“Top3 品牌”和“Top3 产品”不再并排，各自占据一整行宽度。

每个排行条目由名次、名称和杯数组成：

- 名次保持现有暖色强调。
- 名称使用剩余宽度并允许自然换行，不设置单行省略。
- 杯数保持单行、右对齐，并与第一行文字顶部对齐。
- 卡片高度随内容自然增长，页面继续使用现有纵向滚动。

## 数据与状态

`Dashboard`、`ShareValue` 和 `RankedValue` 保持不变。月度和年度模式继续共用 `DashboardContent`，因此同一布局同时覆盖两种模式。

空数据状态保持现有“—”展示。极长的用户自定义名称允许卡片增高，不重新引入最大行数或省略号。

## 可访问性

现有图例和排行的完整 `contentDescription` 保留。视觉文字与无障碍描述使用相同的完整名称、杯数和占比信息。

## 测试与验收

先增加能够在旧实现上失败的 Compose 回归测试，再修改生产代码。

验收覆盖：

1. 320dp 宽度下，咖啡类型和品牌占比分别为整行宽卡片。
2. 320dp 宽度下，Top3 品牌和 Top3 产品分别为整行宽卡片。
3. 长品牌名与长产品名会产生多行文字布局，而不是单行省略。
4. 名称和统计值的边界都位于所属卡片内。
5. 月度与年度模式继续展示同样的四张统计卡片。
6. 既有 Insights 单元测试和 Compose 测试保持通过。

## 预览方案

采用用户确认的 B 方案：整行宽卡片。对比预览保存在会话可视化目录中，仅用于设计确认，不属于应用运行时资源。
