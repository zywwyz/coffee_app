# A 方案二轮：日历主次与全页统一

用户试用反馈：日历头重脚轻、产品图小；豆库和总结需要重新设计并与日历一致。延续已批准的奶油纸底、橄榄绿和照片便签方向，用户已授权调整。

## 实施决定

- 日历移除重复英文页眉，标题、显示模式和设置同排，月份单独一排紧凑导航。移除因 340dp 阈值产生的大块空白。保持点击目标，窄屏及放大字体验收。
- 日历宽度尽量使用屏幕，照片格改为竖向比例、缩减内外边距，保持完整图 Fit。保留本月摘要、最近一杯和底部固定记录操作，不强求所有内容同时塞入首屏。
- 豆库为照片收藏册：胶囊分类、白色品牌卡、双列产品照片卡、完整图片和两行品名；豆子区统一纸卡。保留管理功能和确认流程。
- 总结为月度手账：紧凑标题及周期选择，胶带摘要页、清晰的主次指标、偏好图表、排名清单与照片回顾。保留所有统计内容与计算逻辑。
- 不修改存储、备份、导入、统计计算、网络或权限。

## 验收计划

1. 窄屏 320dp、字体 1.3 下模式控件与标题同排，照片实际宽至少 38dp、高至少 48dp；小屏最近记录不被按钮遮挡。
2. 复用相关 Compose 交互测试与图片回退合约。
3. 生成真实 Compose 首页、豆库、产品、月度/年度总结预览并目视检查。
4. 模块单测、lint、Debug APK 构建；更新项目状态与交付路径。
